This is a React-based project that displays the Maersk Q2 2025 report using a PDF viewer.
When the user clicks on reference [3] in the analysis section, the related text inside the PDF (“Gain on sale of non-current assets”) gets highlighted.

Features

1.Built entirely with React

2.Interactive PDF viewing

3.Text highlighting on reference click

4.Simple and clear user interface


Project Structure

1.App.js – Main layout and highlight logic

2.PdfViewer.js – PDF rendering and highlight handling

3.App.css – Basic styling

4.report.pdf – PDF used for analysis
